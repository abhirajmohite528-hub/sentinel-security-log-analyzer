# Sentinel — Cybersecurity Log Analyzer

## Problem
Suspicious login activity can be difficult to identify
manually in application logs.

## Solution
Analyze login logs and generate alerts for suspicious
patterns, such as repeated failed login attempts.

## Target Users
- Student developers
- Small development teams
- IT support personnel

## MVP Features
1. Import CSV and JSON logs
2. Validate and parse log data
3. Detect repeated failed logins
4. Store events and alerts in SQLite
5. Display alerts on a dashboard
6. Filter and review alerts

## Technology Stack
- Python 3.11
- FastAPI
- SQLite
- HTML, CSS, JavaScript
- Git and GitHub
- pytest
